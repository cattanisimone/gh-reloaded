#69 · Redesign Options as a compact, consistent settings UI

Size: normal (new layout, all of options/ touched) · Goal: turn the landing-page-style Settings into a compact settings app, and move Standup's tuning from Features to Advanced, without touching a single stored key.

What changes for users

  • No hero, glows or marketing copy: a slim header, a left sidebar (Features · GitHub tokens · Quick-create · Advanced) and one section shown at a time.
  • Features is a dense list of toggles. Configure → appears only on Quick-create, Standup mode and My Issues, and jumps to their settings.
  • Standup's Stale after and Review-like statuses move to Advanced › Standup mode, next to Advanced › My Issues by project.
  • Light and dark each use one family of surfaces (sidebar and content match) and follow the OS. Orange is used only for the active item, switches and focus.
  • Every saved setting, token and shortcut keeps working: same storage keys, same defaults, same save behaviour.

Risks and open questions

  • One panel at a time, or one scrolling page with a sticky sidebar? The mockup's breadcrumb points to panels. Default: panels via the hash, as in the navigation map.
  • Mockup PNGs show a fictional "v0.11" and some details that will differ in the final page. Default: bring them in as the issue asks, and say in the PR where the implementation differs.
  • Default theme goes from dark-first to the OS setting with light as the base. Dark-OS users see no change. Default: as the issue says.
  • Shorter help copy: I will trim the Tokens prose, but the permission boxes, SSO note and privacy note keep their substance (token-docs.test.js checks them). Default: shorten the prose, keep every fact.
  • "Help & support" in the mockup: Default: one header link to the repository's Issues page; Website and Repository links move to the sidebar footer.

Out of scope

  • Any github.com-side feature behaviour, new token types, a redesign of token permissions, or the public website.
  • New settings, storage migrations, or a manual theme switch.
