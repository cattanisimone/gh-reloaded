#49 · Quick-create buttons fall back to floating on Projects pages

Size: simple (a selector fix in one function, no new UI, permission or storage) · Goal: put the buttons back in the project top bar on GitHub's current markup.

What changes for users

  • The quick-create buttons show up in the project top bar again, between Insights/Workflows and Project details/"…".
  • They still float at the bottom-right only when no top bar can be found.
  • Nothing changes visually compared with screenshots/quick-create.svg, so there is no mockup.

How it works

Every class is matched by its local name followed by __ (today's naming), with the old index-module__ prefix kept as a fallback. This is the same rule #46 applied to the board features.
