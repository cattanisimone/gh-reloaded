#78 · Personal PR triage on repository pull request lists

cattanisimone/gh-reloaded#78 · Size: normal · Goal: on /<owner>/<repo>/pulls, show on each row of the native list whose move it is, mine or someone else's, without changing the list itself.

What changes for users

  • Each open PR row of the native list gets one small label after its existing metadata: Your turn · Review requested, Waiting on author, and so on. Rows with nothing for me stay unchanged.
  • One line above the list, labelled On this page: counts of Your turn and Waiting on others. Each count is a button that moves focus to the next matching row. A Hide triage link turns the feature off.
  • The native search, filters, sort, Open/Closed tabs, pagination, unread and check widgets, and links stay as they are. No row is hidden, moved or duplicated.
  • Without a token, or when GitHub refuses or fails a request, labels say Triage unavailable (or nothing) and never guess an action.
  • A switch in Settings → Features, on by default. It takes effect immediately and leaves no markup behind when off.

Data, permissions, privacy

  • No new permission (api.github.com is already granted). Token: the one mapped to the repository owner, else the default; never another saved token. Fine-grained: Pull requests: Read and Commit statuses / Checks: Read (README lists them).
  • New storage key: ghprtEnabled (boolean). PR facts are kept in memory (60 s cache), never stored. No last-seen tracking.
  • Only PR numbers already visible on the page are queried, in the repository the page shows.

Risks and open questions

  • Team review requests: confirming I am in the team needs read:org and one more query. Default: show the neutral Team review requested label, counted in neither group.
  • Author's draft with no blocker: default no placement (no "finish your draft" nagging); failing checks or changes requested still make it my turn.
  • Default on: the labels are small and the bar can be hidden in one click. Default on, like My Issues.
  • React re-renders may drop injected nodes: re-asserted on each scan from cached facts, with no refetch inside the 60 s cache.
  • Approved, green, author: no placement rather than "merge it", because branch rules may still block. Default as stated.

Out of scope

  • Global github.com/pulls dashboard, notifications, unread tracking.
  • Changing or writing any PR, review or merge state; replacing native filters; hiding or reordering rows.
  • Project-board PR indicators.
