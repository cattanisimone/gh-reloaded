What changes for users

  • The primary install path is the Chrome Web Store listing (checked: HTTP 200). The "isn't on the Chrome Web Store yet" line is removed.
  • Unpacked loading stays, renamed Install unpacked (development and manual testing), below the token setup.
  • The token section becomes a table grouped by GitHub's real scope: Repository (Issues, Contents, Metadata) and Organization (Projects).
  • A note on what GitHub does not support: a fine-grained token cannot read Projects owned by a personal account, and each fine-grained token has one resource owner. That is why owner tokens exist.
  • SSO guidance is corrected: fine-grained tokens are authorized for an organization when you create them (and may show as pending until an org admin approves). Configure SSO only applies to classic tokens.

How the permission table was derived

Source: GitHub Docs, "Permissions required for fine-grained personal access tokens" (Projects is listed only under Organization permissions) and "Managing your personal access tokens" (gaps: Projects owned by a user account, several organizations at once; Organization permissions require an organization resource owner).

Risks and open questions

  • User-owned Projects. A fine-grained token cannot read them. A classic token with read:project can, but reading private repos with a classic token needs the broad repo scope, which breaks the least-privilege rule. Default: say it is unsupported for fine-grained tokens and that the Projects-based signals then degrade. Mention a classic token with read:project only for public repos, saved as that account's owner token. Never recommend repo.
  • Settings page says the same wrong things (flat "Projects" row, the SSO "authorize the token" callout). Default: leave it unchanged, list it under Follow-ups. Say if you want the small text fix in this PR, but the title would then become fix:.
  • My Issues issue types. issueType is read through the issue itself, so I don't expect the Organization → Issue Types permission to be needed. Default: not listed.
  • PR type. Default: docs:, no release.

Out of scope
