Settings.

Choose which features run on github.com, connect the GitHub tokens they read with, and set up your quick-create shortcuts. Everything is stored in this browser only.

01 / Features

Choose what runs.

Switch any feature off entirely — it stops running on github.com right away. Experimental ones are still maturing and may change as GitHub's own UI does.

Dependency graph A left-to-right graph below an issue's sub-issues, with blockers and the critical path highlighted.
Quick-create button Buttons on Projects boards that open a new-issue form — set them up under Shortcuts below.
Board dependency arrows Experimental Arrows between dependent cards on a Board view, red when a blocker is behind. Also switchable next to the view tabs.
Full-width board Stretches Board views to the full window, shrinking columns down to 140px before scrolling.
HTML preview Experimental Renders .html files from PR diffs and file pages, sandboxed away from your GitHub session.
02 / GitHub tokens

Connect GitHub.

The default token covers every repository owner. Add an owner token for an organization or account that needs its own credential — a different fine-grained token, or one authorized for its SSO. A request uses the owner's token, else the default; it never tries saved tokens in turn.

Owner tokens

Organization enforces SSO? Open GitHub token settings ↗ and authorize the token for it — otherwise GitHub answers with empty results or a 404 for that organization.
03 / Quick-create

One click to the right form.

Buttons added to Projects board views, each opening a new-issue form in the repository you choose — handy when work is filed somewhere other than the board's own repo. Scope one to a single board, or leave it on all of them.
