GitHub tokens

The default token covers every repository owner. Add an owner token for an organization or account that needs its own credential — a different token, or one authorized for its SSO. A request uses the owner's token, else the default; it never tries saved tokens in turn.

Owner tokens

Organization enforces SSO? For a classic token, open GitHub token settings ↗ and choose Configure SSO; a fine-grained token is approved by the organization instead. Without it GitHub answers with empty results or a 404 for that organization.
