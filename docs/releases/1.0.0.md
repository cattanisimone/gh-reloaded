# GH Reloaded 1.0.0

GH Reloaded 1.0.0 is the first stable release: the core experience is ready for regular use. It graduates the existing extension; it adds no new permission, no telemetry and no change to saved settings.

## What is in 1.0.0

- **Dependency graph**: embedded in an issue and full-screen, with refresh, dependencies and the critical path.
- **Projects boards**: dependency arrows, full-width board and Standup mode, plus Quick-create.
- **My Issues by project**: your issues grouped by Project and Status, with a collapsible sidebar.
- **HTML preview**: render an `.html` file from a repository in a sandbox (still labelled Experimental).
- **Settings**: feature switches, one token per repository owner, **Verify access** on every token card, Quick-create and Advanced options.

## Privacy and permissions

Same as 0.14.0: the `storage` permission and `https://api.github.com/*` only. Nothing is collected or sent anywhere except to GitHub, with your own token. Saved options and tokens carry over on update.

## Known limitations

- Projects owned by a personal account need a classic token with `read:project`.
- A fine-grained token has one resource owner, so several owners need one token each.
- Organization approval or SSO can make data come back empty until authorized.
- GitHub can change its pages; a feature whose anchor is gone stays hidden until updated.

## What comes next

Focused 1.x releases, for example personal pull request triage. Nothing here blocks on them.
