## Permissions and safety

- Permissions are unchanged: `storage`, host access to `https://api.github.com/*`, content scripts on `https://github.com/*`. No new permission to accept on update.
- No remotely hosted code: a search of the shipped paths for remote `<script src>`, `eval(` and `new Function` finds nothing.
- Release Please still owns the version, changelog, tag and release; `CHANGELOG.md` is generated.
