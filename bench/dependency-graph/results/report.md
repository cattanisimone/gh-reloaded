# Dependency graph layout benchmark

Generated by `npm run bench:graph` --quick: sizes 8, 20, 40, 2 seeds per kind, 9 kinds (chain, diamond, fanout, fanin, dense, longspan, islands, external, cycle), embedded and full-screen card sizes, timing over 5 runs. Fictional data only.

Every metric is computed on the rendered edge paths (each curve flattened to a polyline), so all engines are scored the same way. `current` is the renderer as it was before this change. Cycle fixtures are excluded from the readability columns (every engine handles cycles differently) and counted in the gates.
